# OpenDoor — Prize Proof Matrix

## Real-world impact

**Claim:** Accessibility planning often depends on operational facts that online sources cannot reliably establish.

**Proof:** Show an outing where at least one critical requirement is unresolved digitally and is resolved or explicitly left unresolved by a real CALL-E call.

## Quality of idea

**Claim:** CALL-E is used as a selective physical-world verification actuator inside a constraint-satisfaction workflow rather than as a generic calling feature.

**Proof:** Show the agent detecting exactly which requirements require a call, why, and how the whole outing result changes.

## Technical implementation

**Claim:** CALL-E is genuinely used at runtime with bounded calls, structured results, idempotency, reconciliation, and deterministic local policy.

**Proof:** Show call state + structured result + evidence normalization + final constraint assessment.

## Product experience & demo

**Claim:** Users receive a trustworthy answer to “Can I actually go?” rather than a generic list of accessibility claims.

**Proof:** One polished 3-minute story with an unresolved case and a successful case.

## Causal proof chain

`user outing goal`
→ `explicit accessibility constraints`
→ `digital evidence gap`
→ `critical-gap reasoning`
→ `human authorization`
→ `CALL-E verification`
→ `structured evidence`
→ `deterministic constraint evaluation`
→ `whole-outing feasibility`
→ `evidence brief`

## Anti-proof

Do not let the demo degenerate into:

- generic phone-call transcript playback;
- accessibility directory browsing;
- AI-generated confidence scores;
- automatic booking;
- unsupported claims of universal accessibility.
